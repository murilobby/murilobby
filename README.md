# Murilo Lobo

Computer Engineering student at UFRN (Natal, Brazil), currently focused on C++ and computer vision.

## Projects

- **[epi-detection](https://github.com/murilobby/epi-detection)**: helmet and vest detection with worker tracking (YOLOv8s + ByteTrack). mAP50 of 0.653 on the test set and no false helmet alarms in the two test videos.
- **[OtimizadorPC](https://github.com/murilobby/OtimizadorPC)**: Windows 11 optimizer for gaming in C#/WPF: 54 tweaks with backup, NVIDIA driver settings and before/after measurements. Version 0.5, in testing.
- **[bigint-cpp](https://github.com/murilobby/bigint-cpp)**: arbitrary-precision integers in C++11 with manual memory management, built on a course template. Tests compare results with native arithmetic and run in CI with ASan and UBSan.
