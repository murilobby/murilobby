## Research

- **Undergraduate research (PIBIC)** at the LAR lab, UFRN, advised by Prof. Helton Maia: real-time pose estimation on an NVIDIA Jetson Orin Nano, comparing video pipelines (OpenCV, GStreamer and DeepStream 7.1) with YOLO11n-pose in PyTorch and TensorRT. The code is not public.

## Projects

- **[epi-detection](https://github.com/murilobby/epi-detection)**: helmet and vest detection with worker tracking (YOLOv8s + ByteTrack). mAP50 of 0.653 on the test set and no false helmet alarms in the two test videos. Unit tests run in CI.
- **[OtimizadorPC](https://github.com/murilobby/OtimizadorPC)**: Windows 11 optimizer for gaming in C#/WPF: 54 tweaks with backup, NVIDIA driver settings and before/after measurements. Version 0.5, in testing.
- **[bigint-cpp](https://github.com/murilobby/bigint-cpp)**: arbitrary-precision integers in C++11 with manual memory management, built on a course template. Tests compare results with native arithmetic and run in CI with ASan and UBSan.
